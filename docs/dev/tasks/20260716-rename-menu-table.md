# 메뉴 테이블명 복수형 변경

## 작업 목적

메뉴 엔티티가 사용하는 테이블명을 `menu`에서 `menus`로 변경하고 관련 초기 데이터와 DB 문서를 일치시킨다.

## 변경 범위와 계획

- 변경할 영역: 메뉴 엔티티 테이블 매핑, H2 초기 데이터 SQL, ERD
- 변경하지 않을 영역: API 경로와 응답, 메뉴 조회 로직, 데이터 내용
- 구현 방향: 테이블명을 사용하는 모든 현재 원본을 `menus`로 통일한다.
- 검증 방법: 전체 테스트, `git diff --check`

## 변경 결과

- 핵심 변경:
  - 메뉴 엔티티의 테이블 매핑을 `menus`로 변경했다.
  - H2 초기 데이터의 입력 대상과 ERD의 테이블명·외래 키 참조를 `menus`로 통일했다.
- 변경 파일:
  - `src/main/java/com/example/cafe/menu/Menu.java`
  - `src/main/resources/data.sql`
  - `docs/db/ERD.md`

## 검증과 남은 사항

- 실행한 검증과 결과:
  - `./gradlew test`: 성공, 전체 테스트 2개 통과
  - `git diff --check`: 성공
  - 단수형 테이블 참조 검색: 남은 참조 없음
- 실행하지 못한 검증: 없음
- 남은 제한사항과 사용자 조치: 없음
