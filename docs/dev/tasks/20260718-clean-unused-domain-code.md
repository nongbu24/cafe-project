# 도메인 미사용 코드와 반복 코드 정리

## 작업 목적

각 도메인의 사용하지 않는 코드와 반복되는 구현을 확인하고, 기능을 유지하면서 더 짧고 단순한 구조로 정리한다.

## 변경 범위와 계획

- 변경할 영역: 주문 이벤트 퍼블리셔, 메뉴/주문 시간 변환 코드, 작업 기록
- 변경하지 않을 영역: 공개 API 계약, DB 구조, 인증·인가 정책, 비즈니스 동작
- 구현 방향: 실제 참조가 없거나 구현체 하나만 남는 불필요한 타입을 제거하고, 합친 뒤 전체 코드 길이가 줄어드는 반복만 공통 메서드로 분리한다.
- 검증 방법: `./gradlew test`, `git diff --check`, `git status --short`

## 변경 결과

- 핵심 변경: 단일 구현체만 남아 기능에 기여하지 않던 `OrderEventPublisher` 인터페이스를 제거하고, 한국 시간 `OffsetDateTime` 변환과 `INVALID_REQUEST` 예외 생성을 공통 메서드로 정리했다. 정리 전 관련 Java 코드는 573줄, 정리 후 관련 Java 코드는 569줄로 줄었다.
- 변경 파일: `ApplicationException`, `DateTimeUtils`, 인증/메뉴/주문/포인트/회원 일부 서비스와 컨트롤러, 주문 이벤트 퍼블리셔

## 검증과 남은 사항

- 실행한 검증과 결과: `./gradlew test` 성공, `git diff --check` 성공, `git status --short`로 변경 파일 확인
- 실행하지 못한 검증: 없음
- 남은 제한사항과 사용자 조치: 없음
